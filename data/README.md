# Project Datasets

This folder contains the datasets used in the Dual Dependency Gap project.

## Folder Structure

- **raw/**: Original datasets before data cleaning, organized by category.
- **cleaned/**: Datasets after data cleaning and preparation, organized by category.

## Data Categories

The datasets are organized by the project's main strategic sectors, including agriculture and food commodities, fertilizers, and iron and steel trade.

Each category may contain a raw version and a cleaned version to distinguish the original data from the data prepared for analysis.

## Important Note

The forecasting notebook currently expects an Excel workbook named `EGYPT_2030_FINAL_ALL_YEARS_MODEL.xlsx`. The category-specific datasets in this repository are separate files and may not be a direct replacement for that workbook.

Only datasets that are permitted for public sharing should be included in this repository.
